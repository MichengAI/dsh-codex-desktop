> DSH Codex Desktop ist eine von der Community gepflegte Desktop-Distribution für DeepSeek Harness. Es ist kein offizielles Produkt von DeepSeek AI.

DSH Codex Desktop macht [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) zu einer nativen, sofort startbereiten Arbeitsumgebung. Das Installationsprogramm bündelt die erforderliche Node.js-Laufzeitumgebung und das lokale DSH-System: installieren, starten und direkt loslegen.

## Download und Einstieg

Laden Sie das aktuelle Installationspaket von den [GitHub Releases](https://github.com/MichengAI/dsh-codex-desktop/releases) herunter.

| Plattform | Paket | Anleitung |
| --- | --- | --- |
| Windows x64 | `.exe`-Installer oder `.zip`-Archiv | Installer ausführen und **DSH Codex Desktop** über das Startmenü öffnen. |
| macOS Apple Silicon / Intel | `.dmg`-Installer | Disk-Image öffnen, App in den Programme-Ordner ziehen und starten. |
| Linux x64 / ARM64 | `.AppImage` oder Debian / Ubuntu `.deb` | Entsprechendes AppImage ausführen oder `.deb`-Paket installieren. |

1. Paket für Ihre Plattform herunterladen.
2. **DSH Codex Desktop** installieren und öffnen.
3. Warten, bis der integrierte DSH-Dienst hochgefahren ist.
4. Aufgabe erstellen, Modell auswählen und am Projekt arbeiten.

## Umfassende Desktop-Funktionen

| Bereich | Funktion |
| --- | --- |
| **Arbeitsbereich** | Projekt- und Aufgabenverwaltung, Chats, Modellwahl und Berechtigungssteuerung in einem nativen Fenster. |
| **Experten-Profile** | Spezialisierte Rollen für Code-Reviews, Architektur, Frontend, Backend und DevOps aktivieren. |
| **Skill-Center** | Lokale und geteilte Agent-Skills zentral verwalten, aktivieren und hochladen. |
| **Archivverwaltung** | Frühere Chats durchsuchen, wiederherstellen oder sicher entfernen. |
| **IM-Assistent** | Messaging-Kanäle wie DingTalk, Feishu, Lark, WeChat, QQ, Telegram an zentraler Stelle einrichten. |
| **Plugin-Marktplatz** | DSH-Erweiterungen direkt in der Desktop-App entdecken, installieren und aktualisieren. |
| **Automatisierung** | Wiederkehrende Aufgaben mit integriertem Scheduler steuern. |
| **Sichere Laufzeit** | Lokale Loopback-Bindung mit geschützter App-Hülle. |

| IM-Assistent | [`@michengai/dsh-im-connect`](https://github.com/MichengAI/dsh-im-connect) |
| Aufgabenplanung | [`@michengai/dsh-automation`](https://github.com/MichengAI/dsh-automation) |
| Erweiterbare Seitenleiste | [`dsh-better-sidebar`](https://github.com/omdsh-dev/DSH-better-sidebar) |
| Nebenfragen stellen | [`@michengai/dsh-btw`](https://github.com/MichengAI/dsh-btw) |
| Code-Vereinfachung für Git | [`@michengai/dsh-simplify`](https://github.com/MichengAI/dsh-simplify) |
| Fehlerdiagnose & Wiederholungen | [`@michengai/dsh-pua`](https://github.com/MichengAI/dsh-pua) |
| Unabhängiges Code-Review | [`@michengai/dsh-code-review`](https://github.com/MichengAI/dsh-code-review) |

Weitere Plugins können über den Marktplatz nachinstalliert werden. Die Desktop-App trennt ihre eigene Laufzeitumgebung strikt von den Community-Plugins des Profils.

Die Desktop-Bridge wird mitgeliefert und nur injiziert, wenn Desktop den DSH-Dienst startet.

## DSH Produkt-Ökosystem

Für eine vollständige Desktop-Arbeitsumgebung laden Sie [DSH Codex Desktop](https://github.com/MichengAI/dsh-codex-desktop/releases) herunter. Bestehende [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)-Installationen können Plugins anhand der jeweiligen README hinzufügen:

| Plugin | Beschreibung |
| --- | --- |
| [Codex UI](https://github.com/MichengAI/dsh-codex-ui) | Projekte und Chats strukturieren, Aufgaben suchen und Chat-Verlauf navigieren |
| [Agency Agents](https://github.com/MichengAI/dsh-agency-agents) | Spezialisierte Rollen für Ihre Aufgabe auswählen |
| [Skills Manager](https://github.com/MichengAI/dsh-skills-manager) | Lokale Skills finden, aktivieren, erstellen und importieren |
| [Archive Manager](https://github.com/MichengAI/dsh-archive-manager) | Archivierte Chats durchsuchen, wiederherstellen oder bereinigen |
| [IM Connect](https://github.com/MichengAI/dsh-im-connect) | Aufgaben per Messaging senden und Antworten empfangen |
| [Automation](https://github.com/MichengAI/dsh-automation) | Aufgaben planen und Ausführungen überwachen |
| [BTW](https://github.com/MichengAI/dsh-btw) | Nebenfragen stellen, ohne den Hauptlauf zu unterbrechen |
| [Simplify](https://github.com/MichengAI/dsh-simplify) | Code innerhalb Ihrer Git-Änderungen optimieren |
| [PUA](https://github.com/MichengAI/dsh-pua) | Den Agenten nach Fehlern zu neuen Lösungsansätzen anleiten |
| [Code Review](https://github.com/MichengAI/dsh-code-review) | Unabhängiges Agenten-Review über `/review` anfordern |

Die Anwendung bindet zudem [DSH Better Sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) und [App Market](https://www.npmjs.com/package/dshmarket) ein.

## Updates und Wiederherstellung

- **Desktop-Updates**: Werden automatisch beim Start geprüft und benachrichtigen Sie bei neuen Versionen. In Einstellungen → Updates kann der automatische Download gewählt werden. Die Installation erfordert stets eine Bestätigung.
- **DSH neu laden**: Ermöglicht einen schnellen Neustart des DSH-Dienstes über das Tray-Menü ohne Neuinstallation der Desktop-App.
- **Plugin-Updates**: Werden über die DSH-Einstellungen und den Plugin-Markt verwaltet.
- **Wiederherstellungsmodus**: Isoliert fehlerhafte Plugins beim Start, sodass der Arbeitsbereich sicher gerettet werden kann.

## Datenschutz und Sicherheit (Privacy and security)

- DSH-Konfiguration, Sitzungen und Zugangsdaten verbleiben im Benutzerverzeichnis. Eine Deinstallation löscht diese Daten nicht.
- Der Launcher akzeptiert ausschließlich validierte lokale Loopback-Adressen `127.0.0.1`.
- Externe Links öffnen im Standard-Webbrowser des Systems.
- Electron nutzt strikte Kontextisolation und Sandboxing ohne Node.js-Integration in der DSH-Webseite.
- Ihre konfigurierten Modelle und DSH-Tools können eigene Netzwerkanfragen ausführen. Bitte prüfen Sie deren Datenschutzrichtlinien.
