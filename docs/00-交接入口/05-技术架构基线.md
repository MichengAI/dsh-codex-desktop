# 技术架构基线

更新时间：2026-10-20 21:39（Asia/Shanghai）

本页只提供交接摘要，完整约束以[桌面启动器架构基线](../03-技术架构/00-桌面启动器架构基线.md)为唯一文档事实源，不在此维护第二份版本表。

- Electron 承载本地 DSH HTTP 工作台；仅接受经校验的 `127.0.0.1` 地址，禁用页面 Node.js 集成，启用上下文隔离。
- 桌面运行时组件由 `dsh-runtime` 管理；社区插件进入用户 Web profile；用户自装的独立官方 bundle 及其声明保留，不能按官方 scope 批量迁移或删除。
- 启动期不扫描清理官方 scope 或未声明包。profile 使用 hoisted 依赖树，顶层包可能是传递依赖；依赖增删由 pnpm 管理，不手工删除包目录。
- loader 锚点优先只是解析顺序，不保证所有插件依赖单例或类身份安全。
- 随包版本和工具链读取[源码清单及打包元数据](../03-技术架构/00-桌面启动器架构基线.md#版本与实现事实源)，不另抄固定版本号。
- 插件安装失败不直接阻断加载；恢复按实际失败证据和用户确认定向隔离，不自动删除无关插件。
- 正常退出走受控关闭通道；超时只处理本应用创建的 PID。卸载保留用户 `.dsh` 数据，不记录密钥或会话正文。

本页与详细基线随仓库交付；其他本地归档仍保持忽略，不是读懂本基线的前置条件。
